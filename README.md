# Tokyo Rental Property Map

[English](README.md) | [日本語](README.ja.md)

A Next.js, TypeScript, Deck.gl, and MapLibre web application that visualizes rental properties across Tokyo, Kanagawa, Saitama, and Chiba with price filters.

## Run locally

```bash
npm install
npm run dev
```

For a production build, use `npm run build` followed by `npm start`.

## Explore the map

Property markers distinguish monthly rent bands: green up to JPY 100,000, yellow JPY 100,000–200,000, and red above JPY 200,000. Use price filters to narrow the display. The map uses Geospatial Information Authority of Japan tiles. Read the Japanese guide's data section for the dataset's scope and limits.
